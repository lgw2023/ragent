1、异步框架接口列表
1.1   创建AI处理任务
1.1.1    接口描述
新增任务执行

1.1.2    接口地址
POST  /sgp/${serviceName}/infers/${serviceVersion}/upredict/infers

 

1.1.3    请求消息
具体的请求参数集字段由模型发布者和业务方协商确定，平台只做转发.

当推理请求中包含多个推理请求参数集时，负载均衡器将所有推理请求参数集作为一个整体，一次性完成服务版本和实例的指定，以及请求转发；当其中某个请求参数集推理失败时，即作为本次请求内所有参数集推理失败。

为支持一次推理请求中携带多个推理请求参数集，请求方需要指定如下字段信息：

参数定义
参数列表

类型

M/O

字段描述

version

String

M

服务协议版本号，与请求携带的一致

meta

JSONObject

M

响应元数据，JSON结构体

reqData

List<JSONObject>

M

真实的请求参数集结构体数组。数组里为JSON结构体。

字段由模型发布者和业务方协商确定，平台只做转发，从3.3节开始是业务使用字段定义

action字段query 表示查询AI处理状态，create表示开始AI处理，cancel标识取消AI处理任务。

类型

子场景标识

 

内层reqData.data对象，JSON结构体，业务定制内容，必须包括taskId、action字段，其他部分业务自己指定，最终会传递到业务自定义组件中。

字段名

1.1.4    响应消息
字段名

类型

M/O

描述

code

Int

O

0表示成功，非0表示失败。对于查询动作，0表示处理完成，状态OK，非0表示失败，具体错误码业务可自定义

des

String

O

结果描述

serviceName

String

O

产生响应的服务名称

serviceVersion

String

O

产生响应的服务版本

respData

List<JSONObject>

O

action为create/cancel时均不返回该字段，仅当action为query且当前状态为已完成才会返回，其余状态不返回。

响应消息格式：

{

  "version": "1.0",

  "meta":{

    "uuid": "1aedfe-23acbef6f-afe7ed8"

  },     

  "result":{

       "code":0,

       "des":"success",

       "serviceName":"video_delogo",

       "serviceVersion":"1.0.0"

   }

}
